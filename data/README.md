# Gestión de datos

La fuente planeada es la Pokédex pública disponible en PokéAPI (https://pokeapi.co/). Todavía no se han descargado datos.

- raw/ contendrá el corte original, sin modificar.
- processed/ contendrá tablas derivadas por código reproducible.
- external/ se reservará para archivos auxiliares con licencia documentada.

Al incorporar un conjunto, registra fuente, endpoint, licencia, fecha de consulta, esquema, transformaciones y limitaciones. No subas datos personales, telemetría privada, archivos grandes ni secretos. El nombre del repositorio no implica que los datos representen Pokémon GO.
